# 운영과 피드백

[← README](../../README.md) · [컨셉과 세계관](concept.md) · [콘텐츠](contents.md) · [에셋 제작](art-pipeline.md)

개발을 시작하고 3주째인 10월 30일에 실서비스를 열었고, 11월 27일까지 운영했습니다. 운영 기간에 15번 업데이트했습니다.

## 지표

11월 17일에 운영 DB 와 모니터링 지표에서 운영자(GM) 계정을 빼고 센 값입니다.

| 지표 | 값 |
|---|---|
| 가입 | 193명 (이 중 98% 가 실제로 플레이) |
| 원정 | 974회 |
| 누적 플레이 시간 | 150시간 이상 |
| 1시간 넘게 플레이한 사람 | 33명 (2시간 넘게 26명) |
| 7일째 재방문율 | 11.3% |

7일째 재방문율은 처음 접속한 날로부터 정확히 7일째 되는 날 다시 플레이한 사람의 비율입니다. 게임 업계 공개 자료와 같은 방식으로 셌는데, PC 게임 상위 10%(6 ~ 7%)보다 높고 모바일 게임 상위 10%(11 ~ 12%)와 비슷한 수준이었습니다.

## 피드백 반영

설문(17명)과 게임 채팅 문의(32건)로 피드백 49건을 받았고, 그중 36건을 반영했습니다.

| 받은 의견 | 반영한 내용 |
|---|---|
| 「접속이 너무 느려요」 | 첫 다운로드 246MB → 116MB, 챕터 입장 25초 → 8초 ([트러블슈팅](../tech/troubleshooting.md#1-입장할-때마다-로딩이-길었던-문제)) |
| 「스킬 레벨업이 안 보여요」 | 스킬 칸에 강화 단계 표시 |
| 「폭탄 고블린 범위가 남아요」 | 쓰러진 뒤 폭발 범위 표시가 남지 않게 수정 |
| 「키가 어색해요」 | 키 설정 변경 기능 추가 |
| 「포션을 들고 다니고 싶어요」 | 포션 칸 추가 |
| 「의태 스킬에 소리가 없어요」 | 보스, 의태 효과음 추가 |
| 「공지가 늦어요」 | 게임 안 공지 기능 추가 |
| 「묘지기가 너무 세요」 | 보스, 몬스터 밸런스 조정 |
| 「옛 1등도 칭호 주나요?」 | 랭킹 1위 칭호를 서버에서 지급 |

## 피드백을 보고 콘텐츠를 늘린 과정

서비스를 열었을 때 할 수 있는 것은 원정뿐이었습니다. 운영 초반 문의 중에 「원정 말고 즐길 거리는 없나요?」와 「멀티에서는 뭘 할 수 있나요?」가 반복해서 들어왔습니다.

원정을 더 늘리는 것보다 다른 방식으로 즐길 모드를 빨리 여는 쪽이 낫다고 판단했고, 원정에 쓴 보스와 맵을 다시 쓰는 방식으로 서브 콘텐츠를 만들었습니다 ([서브 콘텐츠를 빠르게 만든 방법](contents.md#서브-콘텐츠를-빠르게-만든-방법)). 그 뒤 채팅에는 이런 반응이 올라왔습니다 (보낸 사람은 뺐습니다).

- 「생존 모드 재밌던데요」
- 「PvP 같이 하실 분?」
- 「좀 더 재미있어진 것 같아요」
- 「2챕 나오고부터 재미 붙고」
